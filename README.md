### 🚀 Featured Project — Generator Fuel Calculator

A production web app that lets field engineers photograph meter readings and auto-extract data via AI, with an admin approval workflow.

**Live demo:** https://generator-fuel-calculator-2.balancecalc.workers.dev  
**Source code:** https://github.com/subhammallick285-spec/generator-fuel-calculator-2-

**What it does**
- Field technician uploads a meter screenshot
- Llama 3.2 Vision OCR extracts kWh, hour-meter, fuel-filled, and balance
- Auto-crops tall screenshots for reliable extraction
- Admin reviews, corrects, and approves before the record is written
- Persisted in Cloudflare D1 with foreign-key integrity

**Tech stack**
- Front-end: HTML5, CSS3, Vanilla JavaScript (ES2020)
- Backend: Cloudflare Workers (serverless edge)
- Database: Cloudflare D1 (SQLite at edge)
- AI: Cloudflare Workers AI — Llama 3.2 11B Vision
- Auth: Header-based admin key + session storage
